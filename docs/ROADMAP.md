# Phạm vi sau bản giao diện

| Hạng mục | Trạng thái |
|---|---|
| Nhận diện, WorkChat và sáu màn hình | Có mã nguồn và bản dựng 0.1.0 |
| Dự án, nhiệm vụ, tiến độ, hoạt động, nhà cung cấp | Hoạt động trong dữ liệu cục bộ |
| Gói bàn giao, nhập kết quả, đính kèm | Luồng thao tác thủ công |
| Tài khoản, phân quyền dự án và lịch sử kiểm toán máy chủ | Chờ backend |
| Workers, D1, R2, đồng bộ và xử lý xung đột | Chờ triển khai |
| Tích hợp GitHub, CI/CD từ xa và Local Runner | Có mẫu cấu hình CI, chờ kho GitHub |
| Health Monitor, thông báo email, báo cáo tuần | Chờ hạ tầng và nguồn dữ liệu |
| Backup/Restore | Có xuất JSON, chờ sao lưu máy chủ và thử khôi phục |
| PWA cập nhật, Android TWA, APK/AAB | Chờ ứng dụng web có địa chỉ ổn định |
| Staging, Production | Chờ môi trường Staging và nghiệm thu. Production cần Owner phê duyệt |
